# Portfolio Website

A portfolio website showcasing my background, technical skills, education, and web development projects.

## About the Project

I built this portfolio to introduce myself as a Computer Science graduate and present the projects I've worked on while developing my skills in web development.

The website uses a charcoal and emerald color scheme with a responsive layout and simple hover effects.

## Features

- Personal introduction and About section
- Technical skills overview
- Education section
- Featured project cards
- Contact information and contact form UI
- GitHub and LinkedIn links
- Responsive layout for different screen sizes

## Technologies Used

- HTML5
- CSS3
- Font Awesome 6 for icons

## Getting Started

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser.

You can also use the Live Server extension in VS Code to preview the website while developing.
